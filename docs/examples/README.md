# Worked examples

Each example has a netlist in [`examples/`](../../examples). You can load it from the **Examples…** menu or with **Open…**.

Every number quoted in these pages was computed with the engine itself, and most are checked against a closed-form result. Where they come from a finer sweep than the netlist's default, that is noted. The scripts behind them use `tools/measure.mjs`, and the figures are regenerated by `tools/docfigs.py`.

| # | Example | What it shows |
|---|---|---|
